# LDR call planner

Use when the user wants to plan a call with their boyfriend.

## How to use

1. Run `furassistant ldr` yourself first (or ask the user to paste its output) —
   it shows both local times and today's overlap windows.
2. Ask: how long, voice or video, anything to prepare (movie, game, quest session?).
3. Propose 2 concrete slots in BOTH timezones (Bratislava + his US zone).
4. Suggest one cozy activity: `furassistant quest` co-op, movie night, stargazing call.
5. Keep it SFW and sweet. End with one hype line.
